# NIDOX INCY Routing

Автообновляемый профиль маршрутизации для [INCY](https://incy.cc/): важные российские сервисы и локальная сеть идут напрямую (`DIRECT`), всё остальное — через активный прокси (`PROXY`).

Это **не** конфигурация сервера и не подписка: здесь нет ключей, UUID, паролей или адресов VPN-серверов.

## Что делает профиль

| Трафик | Действие |
| --- | --- |
| Локальные, приватные и служебные сети | `DIRECT` |
| Домены и сети из курируемого списка российских сервисов | `DIRECT` |
| Всё, что не совпало с правилами | `PROXY` |

В профиле намеренно нет правила «все `.ru` / `.рф` — напрямую»: такой широкий обход легко отправляет через провайдера неучтённые ресурсы на общих доменах/CDN. Список `hxehex/russia-mobile-internet-whitelist` также намеренно **не** добавляется в `DirectSites`: его автор определяет его как список разрешённых SNI для ограниченной мобильной сети, а не как список сайтов для прямого доступа. Он скачивается лишь как диагностический артефакт `build/sni-allowlist.txt`.

## Быстрый старт в INCY

1. Опубликуйте этот проект в **своём** репозитории GitHub (или разместите `dist/profile.json` на HTTPS-хостинге).
2. Откройте ссылку, подставив свой GitHub-логин и имя репозитория:

   ```text
   incy://autorouting/onadd/https://raw.githubusercontent.com/<owner>/<repo>/main/dist/profile.json
   ```

3. INCY добавит и активирует профиль. Его URL будет проверяться каждые 30 минут; обновление произойдёт, когда прошёл заданный интервал (по умолчанию 24 часа).

В настройках INCY сначала добавьте и проверьте рабочий сервер/подписку. Затем откройте ссылку выше. При необходимости вместо `onadd` используйте `add`, чтобы профиль только добавить, без активации.

## Обновление списка

GitHub Actions запускается раз в сутки, а также вручную. Он:

1. скачивает исходные текстовые списки по HTTPS;
2. отбрасывает комментарии, дубликаты и некорректные значения;
3. не принимает чрезмерно широкие сети (шире `/12` для IPv4 и `/32` для IPv6);
4. генерирует `dist/profile.json`, манифест с SHA-256 и диагностический SNI-список;
5. выполняет тесты и коммитит **только изменившиеся** результаты в ваш репозиторий.

Внешние списки — данные сообщества, не гарантия доступности, полноты или безопасности. Перед эксплуатацией на конкретном операторе протестируйте несколько банков, Госуслуги, локальные устройства и нужные иностранные сервисы. При жёстком фильтре мобильной сети одного профиля маршрутизации недостаточно: способность установить VPN-соединение определяется отдельно оператором, IP сервера и TLS/SNI.

## Локальная сборка и проверка

Требуется Python 3.11+; внешние зависимости не нужны.

```bash
python3 scripts/build.py
python3 -m unittest discover -s tests -v
```

Чтобы собрать без сети из уже скачанных файлов, используйте `--offline`:

```bash
python3 scripts/build.py --offline
```

## Структура

```text
config/profile.template.json  Непеременные настройки INCY
scripts/build.py              Скачивание, валидация и генерация
dist/profile.json             Готовый профиль Autorouting
dist/manifest.json            Происхождение, хеши, статистика
build/sni-allowlist.txt       Диагностический источник SNI (не правило DIRECT)
.github/workflows/update.yml  Ежедневная безопасная пересборка
tests/                        Автотесты парсинга и профиля
```

## Источники и спецификация

- [Официальная документация INCY Autorouting](https://docs.incy.cc/autorouting/) — URL-профиль, deeplink и цикл обновления.
- [Официальная спецификация Routing](https://docs.incy.cc/en/routing/) — поля `DirectSites`, `DirectIp`, `GlobalProxy` и DNS.
- [112fm/OpenSmart-Russia](https://github.com/112fm/OpenSmart-Russia) — курируемые `direct-domains.txt` и `direct-cidrs.txt`.
- [hxehex/russia-mobile-internet-whitelist](https://github.com/hxehex/russia-mobile-internet-whitelist) — SNI/IP-наблюдения для условий ограниченного мобильного интернета; используется только для диагностики.

## Безопасность и откат

- Проверяйте изменения в автоматически созданных коммитах: у источников нет криптографического закрепления содержимого.
- Не добавляйте в правила адрес вашего прокси-сервера или его домен: это может создать маршрут в обход туннеля.
- Не помещайте секреты в `profile.json`, workflow, Issues или Actions logs.
- Чтобы отключить эффект профиля, выберите другой профиль либо удалите «NIDOX · RU direct / proxy fallback» в INCY. Удаление репозитория не отменяет уже установленный профиль на устройстве.

Используйте в соответствии с применимым законодательством, политиками сети и условиями провайдера.
