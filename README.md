# NIDOX INCY Routing

Автообновляемый профиль маршрутизации для [INCY](https://incy.cc/): важные российские сервисы и локальная сеть идут напрямую (`DIRECT`), всё остальное — через активный прокси (`PROXY`).

Это **не** конфигурация сервера и не подписка: здесь нет ключей, UUID, паролей или адресов VPN-серверов.

## Что делает профиль

| Трафик | Действие |
| --- | --- |
| Локальные, приватные и служебные сети | `DIRECT` |
| Домены и сети из курируемого списка российских сервисов | `DIRECT` |
| Всё, что не совпало с правилами | `PROXY` |

В профиле намеренно нет правила «все `.ru` / `.рф` — напрямую»: такой широкий обход легко отправляет через провайдера неучтённые ресурсы на общих доменах/CDN. Список `hxehex/russia-mobile-internet-whitelist` не добавляется в `DirectSites`: он используется только как диагностический артефакт `build/sni-allowlist.txt`.

## Быстрый старт в INCY

**Учётная запись GitHub не нужна.** Репозиторий уже опубликован, поэтому достаточно открыть эту ссылку на iPhone/iPad, где установлен INCY:

[Добавить и активировать профиль в INCY](incy://autorouting/onadd/https://raw.githubusercontent.com/JonesPitkin/nidox-incy-routing/main/dist/profile.json)

Если ссылка открыта не на устройстве с INCY, скопируйте её и откройте там:

```text
incy://autorouting/onadd/https://raw.githubusercontent.com/JonesPitkin/nidox-incy-routing/main/dist/profile.json
```

INCY добавит и активирует профиль. Его URL проверяется каждые 30 минут; новое содержимое применяется после заданного интервала обновления (по умолчанию 24 часа). Сначала добавьте и проверьте рабочий сервер/подписку, затем включайте профиль маршрутизации. Чтобы только добавить профиль, замените `onadd` на `add`.

### Если хотите вести свою копию

GitHub потребуется только в этом случае: сделайте fork или скопируйте проект в свой репозиторий, а затем подставьте в URL свой `<owner>/<repo>`. Это необязательно для обычного использования.

## Обновление списка

GitHub Actions запускается раз в сутки и вручную. Он скачивает исходные текстовые списки по HTTPS, отбрасывает комментарии, дубликаты и некорректные значения, не принимает чрезмерно широкие сети, генерирует `dist/profile.json` и запускает тесты. В репозиторий коммитятся только изменившиеся результаты.

Внешние списки — данные сообщества, не гарантия доступности, полноты или безопасности. Перед эксплуатацией проверьте нужные сервисы и локальные устройства. При жёстком фильтре мобильной сети одного профиля маршрутизации недостаточно: возможность установить VPN-соединение определяется отдельно оператором, IP сервера и TLS/SNI.

## Локальная сборка и проверка

Требуется Python 3.11+; внешние зависимости не нужны.

```bash
python3 scripts/build.py
python3 -m unittest discover -s tests -v
```

## Структура

```text
config/profile.template.json  Непеременные настройки INCY
scripts/build.py              Скачивание, валидация и генерация
dist/profile.json             Готовый профиль Autorouting
dist/manifest.json            Происхождение, хеши, статистика
build/sni-allowlist.txt       Диагностический источник SNI (не правило DIRECT)
.github/workflows/update.yml  Ежедневная безопасная пересборка
tests/                        Автотесты парсинга и профиля
```

## Источники и спецификация

- [Официальная документация INCY Autorouting](https://docs.incy.cc/autorouting/) — URL-профиль, deeplink и цикл обновления.
- [Официальная спецификация Routing](https://docs.incy.cc/en/routing/) — поля `DirectSites`, `DirectIp`, `GlobalProxy` и DNS.
- [112fm/OpenSmart-Russia](https://github.com/112fm/OpenSmart-Russia) — курируемые `direct-domains.txt` и `direct-cidrs.txt`.
- [hxehex/russia-mobile-internet-whitelist](https://github.com/hxehex/russia-mobile-internet-whitelist) — SNI/IP-наблюдения; используется только для диагностики.

## Безопасность и откат

- Проверяйте изменения в автоматически созданных коммитах: у источников нет криптографического закрепления содержимого.
- Не добавляйте в правила адрес прокси-сервера или его домен: это может создать маршрут в обход туннеля.
- Не помещайте секреты в `profile.json`, workflow, Issues или Actions logs.
- Чтобы отключить эффект профиля, выберите другой профиль либо удалите «NIDOX · RU direct / proxy fallback» в INCY.

Используйте в соответствии с применимым законодательством, политиками сети и условиями провайдера.
